# Runtime dependencies for the HOSTED DEMO (Hugging Face Spaces / Streamlit Community Cloud).
#
# Torch-free by design: installs only the edge pipeline + Streamlit, so the build stays small and
# needs no weight download — the TFLite weights are committed under models/. Both platforms
# auto-install this file; the system libs OpenCV needs (libGL/glib) come from packages.txt.
#
#   .[edge]   ai-edge-litert TFLite runtime + core (opencv, Pillow, numpy, PyYAML) — no torch
#   .[app]    Streamlit
#
# For LOCAL DEVELOPMENT install the full stack instead:
#     pip install -e ".[server,app,dev]"        # training, server path, tests
# For an EXACT, reproducible build use the lock file:
#     pip install -e . -r requirements-lock.txt
-e .[edge,app]
